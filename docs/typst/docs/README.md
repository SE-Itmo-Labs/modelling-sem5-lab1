# Как пользоваться шаблоном

Это инструкция для работы с единственным отчётом в проекте. Знать Typst заранее не требуется. Исходники находятся в `docs/typst/`, готовый PDF — в `docs/report/report.pdf`.

## 1. Первая сборка

Нужен Typst 0.15 или новее. Проверьте установку:

```bash
typst --version
```

Из корня проекта выполните:

```bash
make pdf
```

Во время редактирования можно включить автоматическую пересборку:

```bash
make watch
```

Остановить её можно сочетанием `Ctrl+C`. Команда `make clean` удаляет только собранный PDF.

## 2. Что редактировать

| Файл | Назначение |
|---|---|
| `config.typ` | Данные титульника, вариант, содержание и шрифт |
| `sections/task.typ` | Задание |
| `sections/work.typ` | Ход работы |
| `sections/conclusion.typ` | Вывод |
| `sections/sources.typ` | Источники |
| `assets/images/` | Изображения |
| `template/theme.typ` | Размеры, интервалы и общая тема; менять редко |
| `main.typ` | Точка сборки; обычно не менять |

Начните с `config.typ`: замените тестовые ФИО, предмет, номер работы, поток, вариант, город и год. Комментарии прямо в файле объясняют каждый параметр.

## 3. Минимум Typst

Обычный текст пишется как в Markdown. Пустая строка разделяет абзацы.

```typst
Это первый абзац.

Это второй абзац.

== Заголовок второго уровня

=== Заголовок третьего уровня

- пункт маркированного списка
- ещё один пункт

+ пункт нумерованного списка
+ следующий пункт

*полужирный текст* и _курсив_
```

Символ `#` переключает разметку в код Typst. Например, `#pagebreak()` создаёт новую страницу, а `#link("https://typst.app")[Typst]` — ссылку.

Формула внутри строки записывается между знаками `$`: `$a^2 + b^2 = c^2$`. Для отдельной формулы оставьте пробелы сразу после первого и перед последним `$`.

## 4. Разделы и содержание

Содержимое каждого файла раздела хранится внутри конструкции:

```typst
#let work = [
  == Цель работы

  Текст раздела.
]
```

Не удаляйте `#let task = [`, `#let work = [` и соответствующую закрывающую `]`. Заголовки `==` и `===` автоматически появляются в содержании. Глубина задаётся параметром `toc_depth` в `config.typ`.

Главные разделы «Задание», «Ход работы», «Вывод» и «Источники» уже создаются шаблоном — повторять их внутри файлов не нужно.

## 5. Изображения

Скопируйте файл в `assets/images/`, подключите компонент в начале раздела и добавьте рисунок:

```typst
#import "../template/components/figures.typ": report-figure

#report-figure(
  image("../assets/images/example.png", width: 100%),
  width: 85%,
  caption: [Описание изображения],
) <fig:example>
```

Ссылка на него в тексте: `см. @fig:example`. Typst сам подставит номер.

## 6. Таблицы

```typst
#import "../template/components/tables.typ": report-table

#report-table(
  columns: (1fr, 2fr),
  header: ([Поле], [Значение]),
  rows: (
    ([Язык], [Typst]),
    ([Формат], [PDF]),
  ),
)
```

Количество элементов в каждой строке должно совпадать с количеством колонок.

## 7. Код

```typst
#import "../template/components/code.typ": code-block, inline-code

Файл #inline-code("main.py") запускается командой ниже.

#code-block(
  "print(\"Hello\")",
  lang: "py",
  filename: [main.py],
  line-numbers: true,
)
```

Параметр `lang` включает подсветку. Частые значения: `typ`, `py`, `java`, `js`, `sql`, `bash`, `json` и `text`.

## 8. Настройка внешнего вида

Основные параметры находятся в `template/theme.typ`:

- `body-size` — размер обычного текста;
- `heading-1-size`, `heading-2-size`, `heading-3-size` — размеры заголовков;
- `page-margin` — поля страницы;
- `paragraph-indent` — красная строка;
- `paragraph-leading` — расстояние между строками внутри абзаца;
- `paragraph-spacing` — расстояние между соседними абзацами;
- `code-size` — размер кода.

Единицы `pt`, `mm`, `cm` задают абсолютный размер. `em` зависит от текущего размера шрифта. После изменения темы обязательно пересоберите PDF и проверьте переносы.

## 9. Частые проблемы

- **`Typst не найден`** — установите Typst и убедитесь, что команда `typst --version` работает.
- **Изображение не найдено** — путь считается относительно файла раздела; для `sections/*.typ` используйте `../assets/images/...`.
- **Ошибка около скобки** — проверьте парность `()`, `[]` и запятые между параметрами.
- **Заголовок не попал в содержание** — используйте `==` или `===`, а также проверьте `toc_depth`.
- **Times New Roman не работает** — оставьте `Liberation Serif`; он уже предусмотрен как основной вариант без установки шрифтов.
- **Нужен Word** — DOCX не поддерживается: эталонным результатом проекта является PDF.

Точные параметры исходного Word-образца описаны в соседнем файле [`REFERENCE.md`](../REFERENCE.md).
