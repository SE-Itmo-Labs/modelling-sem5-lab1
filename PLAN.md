# План выполнения УИР 1 по моделированию

## 1. Что требуется сделать

Нужно исследовать числовую последовательность варианта 29, подобрать для неё закон распределения по двум начальным моментам, реализовать генератор этого распределения и сравнить исходную и сгенерированную последовательности.

Основной результат работы состоит из трёх частей:

1. программа, которая воспроизводимо выполняет все расчёты;
2. таблицы и графики в формах из задания;
3. отчёт с формулами, объяснением выбора распределения и выводом после каждого этапа.

Python подходит для этой работы лучше Excel: на нём проще обеспечить воспроизводимость генерации, автоматическое построение всех таблиц и графиков и повторную проверку расчётов. Excel можно использовать только для выборочной ручной сверки нескольких значений.

## 2. Исходные данные и важный вывод по варианту

- Вариант: `15 + 14 = 29`.
- В книге `!_УИР1_Варианты_с(2).xlsx` вариант 29 находится на листе `1-50`, в столбце `AD`.
- Последовательность содержит 300 значений, расположенных в строках 2–301.
- Исходные данные следует один раз извлечь в `data/variant_29.txt` или `data/variant_29.csv`. Этот файл станет единственным входом основной программы. Скрипт извлечения из Excel стоит сохранить отдельно, чтобы происхождение данных можно было проверить.

Предварительная проверка столбца варианта 29 дала:

- среднее: примерно `19.6262`;
- выборочная дисперсия: примерно `1107.976`;
- выборочное среднеквадратическое отклонение: примерно `33.2863`;
- коэффициент вариации: примерно `1.696`.

Так как коэффициент вариации больше единицы, основной кандидат по методике Алиева — гиперэкспоненциальное распределение. Это принципиальное отличие от примера Арсения: в его варианте коэффициент вариации меньше единицы, поэтому там использовано гипоэкспоненциальное распределение. Его структуру отчёта можно брать за ориентир, но формулы аппроксимации и генератор копировать нельзя.

Окончательные числа должны быть получены программой, а не перенесены из этого предварительного анализа.

### Этап 1. Рассчитать характеристики исходной последовательности

Для первых `10`, `20`, `50`, `100`, `200` и `300` элементов рассчитать:

- оценку математического ожидания;
- несмещённую выборочную дисперсию с делением на `n - 1`;
- среднеквадратическое отклонение;
- коэффициент вариации `s / |x̄|`;
- полуширины доверительных интервалов для вероятностей `0.90`, `0.95` и `0.99` по распределению Стьюдента:

```text
h = t((1 + p) / 2, n - 1) · s / sqrt(n)
```

Для формы 1 относительное отклонение каждой характеристики считать от результата на 300 значениях:

```text
δ(n) = |θ(n) - θ(300)| / |θ(300)| · 100%
```

Для `n = 300` отклонение должно быть `0%`. В строках доверительных интервалов сравниваются именно полуширины `h`.

Результат этапа:

- `results/tables/form1.csv`;
- вывод о стабилизации оценок и сужении доверительных интервалов с ростом объёма выборки.

Важно не обещать строгую монотонность оценок среднего и дисперсии: на отдельных объёмах они могут изменяться в обе стороны.

Дополнительно нанести ориентировочные границы случайных колебаний `±1.96 / sqrt(300)`. Это позволит обосновать вывод о случайности лучше, чем фраза «коэффициенты небольшие».

### Этап 5. Подобрать аппроксимирующий закон

Для выбора семейства использовать коэффициент вариации полной последовательности:

- `v < 1` — распределение Эрланга или гипоэкспоненциальное;
- `v ≈ 1` — экспоненциальное;
- `v > 1` — гиперэкспоненциальное.

Для варианта 29 ожидается двухфазное гиперэкспоненциальное распределение `H2`:

```text
f(x) = q / t1 · exp(-x / t1) + (1 - q) / t2 · exp(-x / t2),  x ≥ 0
```

Здесь `t1` и `t2` — средние значения двух экспоненциальных фаз, `q` — вероятность выбора первой фазы.

По Алиеву параметры должны удовлетворять:

```text
q ≤ 2 / (1 + v²)
t1 = m · [1 + sqrt((1 - q) / (2q) · (v² - 1))]
t2 = m · [1 - sqrt(q / (2(1 - q)) · (v² - 1))]
```

У двухфазной гиперэкспоненциальной модели три параметра, а по заданию известны только два момента. Поэтому значение `q` нельзя выбирать молча. Рекомендуемый порядок:

1. вычислить допустимую верхнюю границу для `q`;
2. взять простое внутреннее значение, например `q = 0.25`, если оно удовлетворяет ограничению;
3. проверить положительность `t1` и `t2`;
4. показать, что теоретические среднее и дисперсия совпадают с эмпирическими моментами;
5. при неудовлетворительной форме гистограммы сравнить несколько заранее заданных допустимых значений `q`, например `0.20`, `0.25`, `0.30`, и явно описать критерий выбора.

Необходимо различать две дисперсии:

- в форме 1 используется несмещённая выборочная дисперсия с `n - 1`;
- для метода моментов используется эмпирический второй начальный момент с делением на `n`, то есть `m2 - m1²`.

Это различие должно быть явно подписано в коде и отчёте.

Результат этапа: параметры `q`, `t1`, `t2`, интенсивности `λ1 = 1/t1`, `λ2 = 1/t2`, формула плотности и проверка совпадения двух моментов.

### Этап 6. Реализовать генератор

Для каждого нового значения:

1. сгенерировать `U0` из `(0, 1)`;
2. по `U0 < q` выбрать первую или вторую экспоненциальную фазу;
3. сгенерировать независимое `U1` из `(0, 1)`;
4. получить значение методом обратного преобразования:

```text
X = -ti · ln(1 - U1)
```

Сгенерировать 300 значений. Seed передавать параметром командной строки и сохранять в итоговом файле, например `--seed 29`. Это делает результаты повторяемыми на защите.

Программа должна уметь запускаться одной командой, например:

```text
python main.py --input data/variant_29.txt --seed 29 --out-dir results
```

Результат этапа: `results/generated.txt` и сохранённые рядом параметры генерации.

Для сгенерированных данных повторить этапы 1–4:

- характеристики для объёмов 10, 20, 50, 100, 200, 300;
- доверительные интервалы;
- график последовательности;
- автокорреляция для сдвигов 1–10;

В форме 2 процентные отклонения считать от одноимённой характеристики исходной последовательности того же объёма:

δgen(n) = |θgen(n) - θsource(n)| / |θsource(n)| · 100%

Результат этапа:

### Этап 8. Выполнить итоговое сравнение

Подготовить:

1. одну нормированную гистограмму исходной последовательности с наложенной теоретической плотностью `H2`;
2. сравнительный график гистограмм исходной и сгенерированной последовательностей с одинаковыми границами интервалов;
3. форму 3 с автокорреляциями обеих последовательностей;
4. коэффициент корреляции Пирсона между соответствующими элементами двух последовательностей;
5. сравнение средних, дисперсий, СКО и коэффициентов вариации.

Процентное отличие автокорреляций плохо интерпретируется, когда исходный коэффициент близок к нулю. Формальное значение можно посчитать для формы 3, но при `|rsource| < ε` лучше выводить `—` и пояснять причину, а основной вывод делать по абсолютным коэффициентам и доверительным границам.

Низкая корреляция исходной и независимо сгенерированной последовательностей не является недостатком модели. Генератор должен воспроизводить распределение и числовые характеристики, а не значения исходного ряда в том же порядке.

Минимальный набор автоматических проверок:

1. извлекается ровно 300 значений варианта 29;
2. функции статистики правильно работают на маленькой последовательности, для которой результат посчитан вручную;
